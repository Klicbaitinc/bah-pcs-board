Privacy

The BAH & PCS Money Board is a static website. There are no accounts and no login.

This site does not set cookies of its own. It does not run analytics or advertising scripts. The search box runs in your browser. The ZIP index is a file the page downloads when you use search. It is not sent to us as a query.

Checklist boxes are not stored. Refreshing the page clears them.

The email list is not open. The signup box is disabled. This site does not collect email addresses.

Pages are hosted on GitHub Pages. GitHub may log your IP address and ordinary request data while serving the site.

If an affiliate link is connected later and you follow it, that site may set its own cookies. That happens after you leave this site.
